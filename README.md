# the-pm-skill-lib

A complete product-management lifecycle skill library. 15 skills across 5 stages.

| Stage | Skill | Use it for |
|---|---|---|
| 1. Market | pm-market-research | Landscape, TAM/SAM/SOM, segmentation, trends |
| 1. Market | pm-competitive-intelligence | Teardowns, battlecards, competitor move assessment |
| 2. Discovery | pm-customer-discovery | Interview guides, JTBD, surveys, discovery sprints |
| 2. Discovery | pm-research-synthesis | Raw signal → ranked insights |
| 2. Discovery | pm-opportunity-mapping | Opportunity solution trees, continuous discovery cadence |
| 3. Validation | pm-product-ideation | Ideation, concept development, assumption mapping, stress-tests |
| 3. Validation | pm-opportunity-assessment | Business cases, go/no-go, value sizing |
| 3. Validation | pm-experiment-design | Hypotheses, A/B math, MVP test selection, result interpretation |
| 3. Validation | pm-pmf-assessment | Sean Ellis, retention curves, PMF diagnosis & next moves |
| 4. Definition | pm-product-strategy | Strategy docs, vision narratives, positioning (Dunford) |
| 4. Definition | pm-prioritization | RICE/WSJF/Kano, stack-ranking, defending the Won't list |
| 4. Definition | pm-prd-writing | Full PRDs, one-pagers, spec reviews |
| 4. Definition | pm-user-stories | Epics, INVEST stories, Gherkin AC, story maps |
| 5. Launch & learn | pm-launch-gtm | Launch tiers, rollout/flags, readiness, post-launch review |
| 5. Launch & learn | pm-metrics-kpis | North Star, KPI trees, OKRs, tracking plans, metric diagnosis |

Skills cross-reference each other (e.g., pm-prioritization pulls Reach from the pm-metrics-kpis tree; pm-opportunity-assessment routes weak evidence to pm-customer-discovery). Install all for best results.
